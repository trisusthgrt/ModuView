# Frontend (React + Vite + TypeScript)

## Run locally

1. Create `frontend/.env` using `frontend/.env.example`
2. Install + run:

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`

## Environment variables

See `.env.example`:

- `VITE_API_URL` (e.g. `http://localhost:5000`)
